# מחירון תיקונים

אפליקציית ווב (PWA) למחירון תיקונים ומחירון מכשירים, שמתעדכנת מהודעות הספקים בוואטסאפ.

**כתובת:** https://eliyahu669.github.io/Mehiron/

## מה יש באפליקציה
- **שני מחירונים נפרדים:** תיקונים (מחיר החלק הזול ביותר + עלות עבודה + תוספות, מעוגל ל-10) ומכשירים (מחיר ספק + רווח: אחוז לפי קטגוריה, עם מינימום/מקסימום בשקלים, או אחוז שנקבע לפריט מסוים). בפירוט הפנימי מוצג גם הרווח אחרי מע"מ.
- **חיפוש מהיר:** דגם + סוג תיקון ("a54 מסך", "15 פרו סוללה"), או דגם + נפח במכשירים ("17 פרו 256").
- **עדכון מחירון (מנהל):** הדבקת הודעה מוואטסאפ או PDF ← תצוגה מקדימה ← שמירה. כל הסניפים מתעדכנים מיד.
- **ניהול פריטים (מנהל):** הוספה, עריכה, מחיקה ושינוי מחיר – גם לכמה פריטים יחד.
- **ייצוא וייבוא אקסל (מנהל):** בלשונית "פריטים" – קובץ עם שני גיליונות ("מחירון תיקונים", "מחירון מכשירים"). בייבוא: שורה ששונתה מתעדכנת, שורה חדשה נוספת, שורה שנמחקה נמחקת, ושינוי ב"מחיר ללקוח" הופך למחיר ידני. לפני השמירה מוצגת רשימת השינויים לאישור.
- **הרשאות:** המנהל רואה ומשנה הכול. עובד רואה רק מחיר סופי, ויכול לבקש פירוט; המנהל מדליק לו "פירוט פנימי".
- **אחורה בטלפון:** סוגר חלון ← מבטל סינונים ← מנקה חיפוש. במסך הבית: אחורה כפול ליציאה.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `src/lib/normalize.js` | זיהוי ואיחוד שמות דגמים (עברית, אנגלית, קיצורים כמו `15promax`) |
| `src/lib/parser.js` | פענוח הודעות ספקים: טקסט חופשי, טבלאות, ש"ח / ₪, כותרות וואטסאפ |
| `src/lib/pricing.js` | מנוע התמחור: עבודה לפי סדרה וחריגים, איכויות, רווח, עיגול |
| `src/lib/catalog.js` | קטלוג מאוחד וחיפוש |
| `src/lib/publish.js` | קטלוג "מחיר סופי בלבד" לעובדים |
| `src/lib/packing.js` | דחיסת מסמכים גדולים (מגבלת 1MB של Firestore) |
| `src/lib/excel.js` | ייצוא לאקסל וייבוא ממנו (השוואה לערכים שיוצאו, כדי לשנות רק את מה שבאמת שונה בקובץ) |
| `src/lib/store.js` | Firebase (או מצב מקומי לתצוגה מקדימה) |
| `src/ui/useBack.js` | מחוות אחורה של הטלפון |
| `firestore.rules` | חוקי הגישה בשרת |

## בדיקות
```
npm test            # בדיקות יחידה + שכבת הנתונים (רצות גם ב-GitHub לפני כל פרסום)
npm run build:single && npm run test:e2e   # בדיקות דפדפן (Chrome)
```
`npm run test:private` רץ על מחירוני ספקים אמיתיים שלא נמצאים בריפו.

## פרסום
כל מיזוג ל-`main` עובר בדיקות, נבנה ומתפרסם אוטומטית ל-GitHub Pages.
