# מחירון תיקונים

אפליקציית ווב (PWA) למחירון תיקונים ומכשירים, שמתעדכנת מהודעות הספקים בוואטסאפ.

- **חיפוש מהיר**: דגם + סוג תיקון ← מחיר סופי ללקוח לכל רמת איכות.
- **מחיר תיקון** = מחיר החלק הזול ביותר מכל הספקים + עלות עבודה (טבלה לפי סדרה, עם חריגים לסדרה/דגם) + תוספות, מעוגל לכפולות של 10.
- **מחיר מכשיר** = מחיר הספק + אחוז רווח לפי קטגוריה.
- **עדכון מחירון** (מנהל בלבד): הדבקת הודעה / PDF ← תצוגה מקדימה ← שמירה. כל הסניפים מתעדכנים מיד.
- **מצב לקוח** מסתיר עלות, ספק ורווח.

## מבנה
- `src/lib/parser.js` – פענוח הודעות ספקים (טקסט חופשי וטבלאות)
- `src/lib/normalize.js` – זיהוי ואיחוד שמות דגמים (עברית/אנגלית/קיצורים)
- `src/lib/pricing.js` – מנוע התמחור
- `src/lib/defaults.js` – טבלת העבודה, תוספות ואחוזי רווח ברירת מחדל
- `src/lib/store.js` – Firebase (ענן) או מצב מקומי
- `firestore.rules` – חוקי גישה: המשתמש הראשון שמתחבר הוא המנהל, הסניפים צופים בלבד

## הגדרה
1. להדביק את ה-firebaseConfig ב-`src/firebaseConfig.js`.
2. להדביק את `firestore.rules` ב-Firebase ← Firestore ← Rules.
3. ב-Firebase ← Authentication ← Settings ← Authorized domains להוסיף את הדומיין של האתר.
4. כל push ל-`main` נבנה ומתפרסם אוטומטית ל-GitHub Pages.

## פיתוח
```
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה ל-dist
```
