# מחירון תיקונים

אפליקציית ווב (PWA) למחירון תיקונים ומחירון מכשירים, שמתעדכנת מהודעות הספקים בוואטסאפ.

**כתובת:** https://eliyahu669.github.io/Mehiron/

## מה יש באפליקציה
- **שני מחירונים נפרדים:** תיקונים (מחיר החלק הזול ביותר + עלות עבודה + תוספות, מעוגל ל-10) ומכשירים (המחיר הזול מבין הספקים + רווח: אחוז לפי רמת גימור, עם מינימום/מקסימום בשקלים, או אחוז שנקבע לשורה מסוימת). בפירוט הפנימי מוצג גם הרווח אחרי מע"מ.
- **רשימת מכשירים:** כל הדגמים לפי חברה (Apple, Samsung, Xiaomi, אחרים), עם רמת גימור (כניסה / ביניים / דגל / פרימיום, ועוד טאבלטים, אוזניות ושעונים, אביזרים), סדרה, נפח, גרסה ושנת השקה. הודעת ספק מעדכנת רק את המחיר של השורה המתאימה; גרסה חדשה (רשמי, מקביל, DCS…) נוספת כשורה, ודגם או נפח שלא ברשימה מוצגים לבחירה: הוסף / דלג / דלג תמיד. במסך הראשי – סינון לפי חברה ורמת גימור, החדשים קודם.
- **מחירון תיקונים:** לכל דגם וסוג תיקון – כל רמות האיכות (למשל אינסל / OLED / מקורי סרוויס, וכולל / ללא מסגרת), כל אחת בחלק הזול מכל הספקים + עלות עבודה. כל כתיב של ספק ("Incell", "איינסל", "מקורי סאני") מתורגם לשם אחד מרשימת האיכויות שבהגדרות. אפשר להוסיף סוגי תיקון (מתחיל עם "מסך חיצוני"). מנהל מזין מחיר חלק גם ידנית מעמוד הדגם ("עדכן מחיר"), כולל הדבקה של תשובת הספק כמו שהיא.
- **חיפוש מהיר:** דגם + סוג תיקון ("a54 מסך", "15 פרו סוללה"), או דגם + נפח במכשירים ("17 פרו 256").
- **עדכון מחירון (מנהל):** הדבקת הודעה מוואטסאפ או PDF ← תצוגה מקדימה ← שמירה. כל הסניפים מתעדכנים מיד. בחלקים: דגם שלא זוהה מוצג לבחירה (או "דלג תמיד"), מילה שאולי היא איכות – לשיוך, וספק חלקים מתחיל ב"עדכון חלקי".
- **ניהול פריטים (מנהל):** הוספה, עריכה, מחיקה ושינוי מחיר – גם לכמה פריטים יחד.
- **רשימת דגמים לתיקון:** רשימה אחת לכל ספקי החלקים (שם הדגם ו"דגם יצרן" בסמסונג). דגם שנוסף לרשימת המכשירים – ידנית או מעדכון ספק – נוסף אליה אוטומטית; דגם שנמחק מרשימת המכשירים נשאר בה. הודעת ספק ממלאת רק מחירים: היא לא משנה שם דגם או דגם יצרן. שורה מהספק מותאמת קודם לפי דגם יצרן (A125 / A127F) ואחר כך לפי השם; דגם שלא ברשימה מוצג לבחירה: הוסף / זה דגם מהרשימה / דלג / דלג תמיד.
- **טבלה לכל ספק (מנהל):** בלשונית "פריטים" – לכל ספק חלקים טבלה של דגם × חלק (לפי חברה), ולכל ספק מכשירים רשימה עם מחיר לכל שורה. מקלידים מחיר בתא והוא נשמר מיד. עמודות החלקים לכל חברה נקבעות בהגדרות ("סוגי תיקון ואיכויות"): באייפון כמו בקובץ הדוגמה, בסמסונג ושיאומי – עמודה לכל איכות מסך ועוד "כולל מסגרת".
- **קובץ אקסל לכל ספק (מנהל):** ספק חלקים – "מחירון תיקונים" עם גיליון "חלקי חילוף" לכל חברה (Apple / Samsung / Xiaomi; "אחרים" רק כשיש בו דגמים). ספק מכשירים – "מחירון מכשירים" בגיליון לכל חברה במבנה של רשימת המכשירים, עם עמודת "מחיר" אחת. מחיר ללקוח ואחוז רווח נערכים באפליקציה בלבד. בייבוא: תא ששונה מתעדכן, דגם חדש נוסף, ושורה שנמחקה מהקובץ מוחקת רק את המחירים של הספק הזה. קובץ של ספק אחר לא נקלט. לפני השמירה מוצגת רשימת השינויים לאישור.
- **הרשאות:** המנהל רואה ומשנה הכול. עובד רואה רק מחיר סופי, ויכול לבקש פירוט; המנהל מדליק לו "פירוט פנימי".
- **אחורה בטלפון:** סוגר חלון ← מבטל סינונים ← מנקה חיפוש. במסך הבית: אחורה כפול ליציאה.

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `src/lib/normalize.js` | זיהוי ואיחוד שמות דגמים (עברית, אנגלית, קיצורים כמו `15promax`) |
| `src/lib/parser.js` | פענוח הודעות ספקים: טקסט חופשי, טבלאות, ש"ח / ₪, כותרות וואטסאפ |
| `src/lib/pricing.js` | מנוע התמחור: עבודה לפי סדרה וחריגים, איכויות, רווח, עיגול |
| `src/lib/repairs.js` | מחירון תיקונים: סוגי תיקון, רמות איכות ומסגרת, תרגום הכתיב של הספקים |
| `src/lib/devices.js` | רשימת המכשירים: רמות גימור, התאמת הודעות ספקים לשורות, מחיר ללקוח לכל שורה |
| `src/data/devices-default.js` | הרשימה ההתחלתית (מקובץ המכשירים, 2021–2026) |
| `src/lib/catalog.js` | קטלוג מאוחד וחיפוש |
| `src/lib/publish.js` | קטלוג "מחיר סופי בלבד" לעובדים |
| `src/lib/packing.js` | דחיסת מסמכים גדולים (מגבלת 1MB של Firestore) |
| `src/lib/rmodels.js` | רשימת הדגמים לתיקון: בנייה ראשונית, הוספה מרשימת המכשירים, התאמה לפי דגם יצרן ושם |
| `src/lib/partcells.js` | טבלת ספק חלקים: איזה פריט בכל תא, וכתיבה / מחיקה של מחיר בתא |
| `src/lib/excel.js` | קובץ אקסל לכל ספק: ייצוא וייבוא (השוואה לערכים שיוצאו, כדי לשנות רק את מה שבאמת שונה בקובץ) |
| `src/lib/store.js` | Firebase (או מצב מקומי לתצוגה מקדימה) |
| `src/ui/useBack.js` | מחוות אחורה של הטלפון |
| `firestore.rules` | חוקי הגישה בשרת |

## בדיקות
```
npm test            # בדיקות יחידה + שכבת הנתונים (רצות גם ב-GitHub לפני כל פרסום)
npm run build:single && npm run test:e2e   # בדיקות דפדפן (Chrome)
```
`npm run test:private` רץ על מחירוני ספקים אמיתיים שלא נמצאים בריפו.

## פרסום
כל מיזוג ל-`main` עובר בדיקות, נבנה ומתפרסם אוטומטית ל-GitHub Pages.
